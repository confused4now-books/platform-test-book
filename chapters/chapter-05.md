A test page for the platform: every way of writing a DOI should be a link to
doi.org, with the text as written.

A bare DOI: 10.1037/0003-066X.59.1.29.

With the prefix: doi:10.1177/1558689810382532.

As a resolver URL, https://doi.org/10.1111/jtsb.12181, and the old form
(https://dx.doi.org/10.2307/1961840).

Already a link stays as written: [Bhaskar's book](https://doi.org/10.4324/9780203090732).
In code it is left alone: `10.9999/not-a-link`.
